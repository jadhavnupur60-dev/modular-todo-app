# Modular To-Do List App

A simple and colorful To-Do List application built using HTML, CSS, and JavaScript ES6 modules. It allows users to manage daily tasks through an easy-to-use interface.

## Features

- Add new tasks.
- Mark tasks as completed.
- Delete tasks.
- Store tasks in the browser using Local Storage.
- Colorful and responsive user interface.
- Modular JavaScript code for better organization.
- Keyboard-friendly form controls.

## Technologies Used

- **HTML5** – Structure of the application.
- **CSS3** – Styling, gradients, colors, and responsive layout.
- **JavaScript (ES6)** – Application logic and modules.
- **DOM Manipulation** – Updating tasks dynamically.
- **Local Storage** – Saving tasks in the browser.
- **Git and GitHub** – Version control and project hosting.

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension if it is not already installed.
4. Right-click `index.html`.
5. Select **Open with Live Server**.
6. Use the application in your browser.

## How to Use

1. Enter a task in the input field.
2. Click the **Add Task** button.
3. Tick the checkbox to mark a task as completed.
4. Click the delete button to remove a task.
5. Refresh the page to check whether your tasks remain saved.

## Learning Objectives

This project demonstrates the use of HTML, CSS, JavaScript ES6 modules, DOM manipulation, event handling, and browser Local Storage. It also provides practical experience in organizing JavaScript code into separate modules.
